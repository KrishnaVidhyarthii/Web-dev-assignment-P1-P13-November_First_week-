Web Development Lab (P1–P13)
A collection of practical exercises for the Programming for Web Development – I Laboratory course.
Project Structure
The repository is organised by practical:
- P1/ – Terminal and project-folder navigation
- P2/ – Portfolio repository and initial Git commit
- P3/ – Feature branches and Git workflow
- P4/ – GitHub README and version tags
- P5/ – Semantic bio page
- P6/ – Portfolio structure using semantic HTML
- P7/ – CSS design tokens and typography
- P8/ – Sticky navbar and card overlays
- P9/ – Responsive layouts using Flexbox
- P10/ – Portfolio header and footer using Flexbox
- P11/ – Three-column newspaper layout using CSS Grid
- P12/ – Portfolio projects grid using CSS Grid
- P13/ – Comparison of Flexbox and Grid

Each practical's files are stored in its respective folder.
Technologies Used
- HTML5
- CSS3
- Git
- GitHub


How to View
1. Clone or download this repository.
2. Open the required practical folder.
3. Open its index.html file in a web browser.
No additional installation is required for the HTML and CSS practicals.

IMPORTANT
For the initial git P1-P4 projects please check the CODE of README.md as it wraps the regular text in PREVIEW version of README.md version making it harder to read.
