P1: Project Folder and Terminal Navigation
Aim: To create a project folder and learn basic terminal navigation commands.

Commands:

1. Display the current working directory:
pwd


2. List files and folders:
ls


3. Create a project folder:
mkdir MyPortfolio


4. Navigate into the folder:
cd MyPortfolio


5. Create files:
touch index.html style.css


6. Display the contents:
ls


7. Navigate to the parent directory:
cd ..


8. Remove an empty folder:
rmdir MyPortfolio


Result: Successfully created a project folder, navigated through directories, and practiced basic terminal commands.
