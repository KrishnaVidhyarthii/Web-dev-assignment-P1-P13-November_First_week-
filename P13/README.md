P13: Choosing Between Flexbox and Grid for a Shared Layout
Aim: To understand the differences between CSS Flexbox and CSS Grid and implement them in a shared webpage layout.

Theory:
Flexbox	CSS Grid
One-dimensional layout	Two-dimensional layout
Works with rows or columns	Works with rows and columns
Best for navigation bars	Best for page layouts
Aligns items along an axis	Controls rows and columns
Useful for flexible components	Useful for complex layouts

Program: P13.html

Explanation:
- Flexbox is used in the header to arrange the logo and navigation links horizontally.
- CSS Grid is used in the main section to create a two-column layout.
- Flexbox is used in the footer to center the content.
- Media queries make the layout responsive on smaller screens.
Result: Successfully implemented a shared webpage layout using both Flexbox and CSS Grid and understood when to use each layout system.
